## Recommended execution order

1. **001** and **002** first — both are small, independent, and touch
   different files than everything else (no dependency risk).
2. **004** before **005** — 004 changes how `puddle.js`'s module-level
   reduced-motion branch is structured; 005 changes `setupGrid()`'s interval
   startup in the same file. Doing 004 first means 005's steps (which quote
   the pre-004 `setupGrid()`/listener code) should be re-checked against the
   post-004 file rather than assumed identical — 005's plan already calls
   this out under "Repo conventions to follow."
3. **003** last, or independently at any point — it only touches
   `variables.css`, `motion.json`, and two `transition` declarations in
   files that 001/004/005 don't otherwise modify (`global.css`'s
   `.puddle-container--reveal span` rule, `hero.css`). Low risk of
   conflicting with the others, but 003's feel-check depends on 004 having
   made `.puddle-container--reveal` reachable in the live UI — running 003
   after 004 makes that check easier (no need to hand-toggle the class).
4. **006** and **007** at any point after the above — both are additive,
   touch files (`photography.astro`/`masonry.css`, `index.astro`/`about.css`)
   that none of 001-005 or 008 modify, and don't depend on the compiled
   motion tokens existing under any particular name beyond what 002 already
   confirmed (`--transition-slow`, `--ease-out`).
5. **008** last — it edits `puddle.js`'s exact bottom-of-file block, which
   001, 004, and 005 have all already reshaped from the original audit
   commit. Running 008 after 001/004/005 have landed (as they now have,
   per the status column above) means its "current code" excerpts match
   what's actually in the file.

## Dependencies

- 005 depends on 004 having landed first (see above) if both are executed
  in the same pass.
- 003's verification step is easier after 004 lands, but 003 does not
  require 004 to be functionally correct.
- 001 and 002 have no dependencies on any other plan.
- 008 depends on 001, 004, and 005 having already landed in `puddle.js` —
  its plan quotes the current (post-001/004/005) bottom-of-file block, not
  the original audit-commit version.
- 006 and 007 have no dependencies on any other plan or on each other.

## Not planned (see audit for detail)

- `hero.css`'s hover-bounce icon nudge is currently dead code (the `Hero`
  component isn't rendered on any live page after the redesign) — not
  actionable until/unless the component is reinstated.
