# sam-site

Astro portfolio site. Package manager is pnpm (`pnpm dev`, `pnpm build`).

## Design

Before writing or changing any UI, CSS or markup, read [DESIGN.md](DESIGN.md). It holds the rules that apply everywhere and an index of topic files in [docs/design/](docs/design/): colors, typography, layout, actions, motion, surfaces. Read the topic file for the task you are doing.

A token, variant or class that is not named in those docs does not exist. Do not invent one.
